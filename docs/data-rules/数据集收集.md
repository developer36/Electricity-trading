# 电价预测相关数据集收集

当前项目采用山东 `price_forecast` 聚合数据，并补充 Open-Meteo / ERA5 历史天气，详见 [README](README.md)。以下仅为收集资料，不自动下载、不进入当前模型数据流程。调研日期：2026-11-02。

## 1. 广东现货市场多源基准（暂不使用）

用户提供的论文线索对应以下 [Zenodo 数据记录](https://zenodo.org/records/20698386)。目前核验的是数据记录及其描述，尚未取得论文全文或数据文件，也未确认其期刊发表状态。

| 项目 | 记录描述与当前状态 |
| --- | --- |
| 标题 | A multi-source benchmark dataset for day-ahead electricity-price forecasting in the Guangdong spot market |
| DOI | [10.5281/zenodo.20698386](https://doi.org/10.5281/zenodo.20698386) |
| 采集区间 | 元数据列示 2023-06 至 2026-06；各表实际覆盖、缺失情况待取得文件后核验 |
| 组织方式 | 北京时间小时网格，17 张表、152 个有文档说明的字段 |
| 预测目标 | 全省日前与实时结算价格；可用于日前或实时任务 |
| 多源内容 | 官方日前边界预测、21 城市提前 24/48 小时的天气预报、节点价格信号，以及燃料/碳价、台风接近程度与新闻情绪等 |
| 防泄漏设计 | 描述称区分投标时可用字段与事后/结算字段；接入后仍需逐列核验 |
| 访问状态 | **Restricted：记录公开，文件受限。** 页面提示登录检查权限，不能视为已开放下载 |

当前暂不下载、申请或接入该数据集。后续若启用，需完成以下核验：

1. 登录记录页检查访问权限与申请入口；如需联系作者，记录所列联系人为 **Xu, Zeling**，具体申请方式以页面或作者回复为准。
2. 取得使用许可、数据字典、样例及文件后，确认负荷与风光预测的具体字段、单位、区域口径和发布时间，并检查目标价格的结算定义。
3. 审计各表时间覆盖与完整性，建立字段可得性清单。节点价格只有在预测发布时点已知时才能作为输入；事后结算字段仅作标签或分析。
4. 将方向预测作为可选辅助任务；记录中提到的方向预测基准不能直接替代本项目的价格回归评估。若研究图神经网络，另行确认节点拓扑或可解释的构图依据，不能仅凭节点价格字段假定已有图结构。

## 2. 山东官方日报采集（其他来源）

[pmos_shandong](https://github.com/YibaiLin/pmos_shandong) 提供从[山东电力交易平台](https://pmos.sd.sgcc.com.cn/)运行日报 PDF 提取实时用电侧小时电价的工具，但仓库不附数据。不同于当前使用的 `price_forecast` CSV，后续接入前需核验官方文件的可访问性、真实覆盖日期、提取精度及使用权限。

## 3. epftoolbox 学术基准

[epftoolbox](https://github.com/jeslago/epftoolbox) 是与电价预测综述论文配套的开放基准与工具箱，提供多个市场的数据和参考方法，适合建立可复现的实验起点。

| 项目 | 备用方案 |
| --- | --- |
| 对照市场 | EPEX-Germany，数据集标识 `DE` |
| 覆盖时间 | 官方文档列示为 2012-01-09 至 2017-12-31，最终以下载文件审计结果为准 |
| 时间粒度 | 小时级；标准基准任务按日预测 24 个价格点 |
| 原有变量 | 历史价格与两个外生时间序列；具体含义、单位和处理方式须按对应市场元数据核验，不能直接假定已包含全部风光与天气字段 |
| 数据入口 | [官方数据说明](https://epftoolbox.readthedocs.io/en/latest/modules/data_extract.html)、[Zenodo 数据记录](https://zenodo.org/records/4624805) |
| 获取方式 | 依照官方文档使用 `read_data(..., dataset='DE')`，或从数据记录下载 `DE.csv`；本项目暂不实现该数据集的下载 |
| 使用依据 | [Lago 等，Applied Energy，2021](https://doi.org/10.1016/j.apenergy.2021.116983) |

下载时记录数据版本、下载日期、文件校验值、许可及引用要求。代码许可与数据许可分别核查；当前尚未验证下载文件的内容与完整性。

## 4. 多源扩展与备选

| 来源 | 用途 | 使用约束 |
| --- | --- | --- |
| [ENTSO-E Transparency Platform](https://transparency.entsoe.eu/) | 调研目标市场电价、负荷及风光出力/预测，建立更新时期的扩展数据集 | 按区域、字段和日期核验覆盖与接口权限；实际值和预测值分开存储 |
| [Open Power System Data](https://data.open-power-system-data.org/time_series/) | 已整理的欧洲电价、负荷、风光时序候选来源 | 页面所列 2020-10-06 版本主要覆盖 2015 至 2020 年中；逐列检查覆盖，不能假定每个市场均具备全部变量 |
| [Open-Meteo 天气预报档案说明](https://open-meteo.com/en/docs/historical-forecast-api) | 调研历史预测版本，构建可按发布时点回放的天气特征 | 拼接的近实时序列不等同于某次日前预报；需核验模型起报时间、提前量、发布时间和档案覆盖 |
| [Kaggle：Hourly energy demand generation and weather](https://www.kaggle.com/datasets/nicholasjhana/energy-consumption-generation-prices-and-weather) | 多源电力与天气数据的备选入口 | 本次未读取到完整数据卡；地区、年份、字段、许可与是否存在未来信息泄漏均待核验，暂不纳入当前研发 |

DE 基准与较新的天气预报档案可能没有时间交集。若无法取得同期、当时可用的预报档案，DE 实验保留原始基准特征；不同市场的数据与实验分别管理；广东暂不使用。
