# 交易回测

待实现。现有滚动测评属于[电价预测模块](../forecasting/README.md)。交易回测需要生成执行、结算和资金流水。

1. 按历史申报时点推进，冻结当时可用的预测、规则和设备状态，调用[出价策略](../bidding/README.md)。
2. 按已声明的出清和执行假设计算成交与实际充放电，逐时校验约束并将实际 SOC 延续到下一交易日。
3. 根据历史结算价格和规则生成收入、购电成本、退化成本与适用的偏差费用。正式收益口径依赖[市场规则核验](../data-rules/README.md)。
4. 使用相同设备、费用、期初期末 SOC 条件与有效样本，对比固定策略、预测驱动策略和事后完美价格参照。完美价格参照仅用于衡量同口径下的优化空间。

保留输入版本、决策时间、申报、成交、执行、SOC 与结算流水，供[交易复盘](../review/README.md)复算。
