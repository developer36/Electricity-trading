# 储能出价

待实现。对应技能解析中的储能运行约束、运筹优化和交易策略。研究依据见[岗位技能解析](page://page_6ae9ff4d99388191aa17b82754fb6ca0)。

- 输入为[日前价格预测](../forecasting/README.md)、申报时点可得的 SOC、设备参数、成本以及[市场规则](../data-rules/README.md)。
- 首版先用点预测建立单储能日前套利模型。目标为卖电收入减去购电和退化成本。显式约束 SOC 转移、容量、功率、充放电效率和期末 SOC。规则或设备要求充放电互斥时，用 MILP 表达。
- 分别记录充放电计划和申报量价，按市场规则定义两者的映射。输出带决策时点的逐时计划、起止 SOC、目标值和求解状态，交给[交易回测](../backtesting/README.md)。
- 扩展方向包括用概率预测构造价格情景、随机或鲁棒优化，以及辅助服务。
